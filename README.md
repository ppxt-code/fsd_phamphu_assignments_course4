# Vite React Project

## Setup

Follow these steps to run the project locally:

```bash
git clone https://github.com/ppxt-code/fsd_phamphu_assignments_course4.git
cd fsd_phamphu_assignments_course4
npm install
npm run dev
```

## Notes

- Make sure Node.js and npm are installed.
- Run the commands from your terminal.
- Open the local URL shown after `npm run dev` starts.
